Sobre o Sistema

O LexMeta é um sistema de gestão jurídica desenvolvido para automatizar o controle de processos, metas e relatórios de escritórios de advocacia.

O sistema substitui o processo manual de geração de dashboards e centraliza as informações em um único ambiente.

Tecnologias Utilizadas

  • Back-end: Java 21 + Spring Boot
  • Front-end: HTML5, CSS3, JavaScript
  • Banco de Dados: MySQL
  • Gráficos: Chart.js
  • Template Engine: Thymeleaf

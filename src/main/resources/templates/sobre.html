LEX META

Sistema de Gestão Jurídica

O LEX META é um sistema desenvolvido para auxiliar na organização e no acompanhamento de processos jurídicos, oferecendo uma gestão mais prática, segura e eficiente para o seu escritório.

📦 Versão do Sistema 1.0
📅 Data de Lançamento 22/04/2025
💻 Desenvolvimento Java • Spring Boot • MySQL
👤 Desenvolvedor William Nakano
🏢 Cliente Douglas Palatucci
ℹ️

Este sistema foi desenvolvido para uso exclusivo do cliente informado. É proibida a cópia, distribuição ou uso não autorizado.

Principais Recursos

  • ✔ Cadastro e consulta de processos
  • ✔ Organização por área jurídica
  • ✔ Acompanhamento de audiências
  • ✔ Geração de relatórios
  • ✔ Suporte a documentos padronizados
